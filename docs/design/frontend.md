# Öffentliche Website

Die visuelle Richtung folgt der gewählten ruhigen, fotografischen Konzeption. Bis echte Objektfotos vorliegen, verwendet die Vorschau abstrakte Flächen mit einem ausdrücklichen Hinweis. Diese Flächen behaupten nichts über die Wohnungen.

Der [shadcn-Preset](https://ui.shadcn.com/create?preset=b8NrBFw21w) hält die ausgewählten UI-Werte fest: Lyra, Stone, Green, Instrument Serif für Überschriften und DM Sans für Fließtext. Die Website verwendet diese beiden Schriften lokal aus Fontsource und eigene, zurückhaltende Grün- und Naturtöne. Der Preset ist eine Referenz für spätere Komponenten, kein eigenes neues Projekt.

Die Website hat DE/EN-Routen für Startseite, drei Wohnungsdetails, Seminar, Kontakt und die rechtlichen Seiten. Der Kalender zeigt unbekannte Feeds als unbekannt und übergibt einen gewählten Zeitraum an das Anfrageformular. Eine Anfrage reserviert keine Nacht. Die Seminaransicht bleibt bis zur Entscheidung über die Wechselzeiten bei einer manuellen Prüfung.
