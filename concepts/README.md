# Visual directions for the rental website

Direction 01 was selected as the visual reference in [Wohnungsseiten und Verfügbarkeitsansicht skizzieren](https://github.com/davidkathrein/vermietung-lustenau-eva/issues/1). These generated images are discussion material for the public frontend. The apartment interiors and landscape details are illustrative, not photographs of the property. Names, body copy, and visual identity are provisional. Do not use the generated imagery as factual accommodation content.

- `01-ruhig-fotografisch.png`: calm, photo-led hospitality direction.
- `02-editorial.png`: bold editorial direction with strong type and a modular grid.
- `03-freundlich-praktisch.png`: welcoming, practical direction with a photo mosaic and clearer information cards.
